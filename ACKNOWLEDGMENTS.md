# Acknowledgments

DeepResearch Agent is an independent, learning-oriented implementation inspired
by the architecture of [HezaoHezao/poirot](https://github.com/HezaoHezao/poirot).
It is not an official Poirot project and is not affiliated with the Poirot
authors.

The project rebuilds the execution path in small, testable stages to understand
how a research agent works. Thanks to the following open-source projects and
their maintainers:

- [Poirot](https://github.com/HezaoHezao/poirot) — research-agent architecture,
  context governance, and long-term memory design inspiration (MIT License).
- [LangChain](https://github.com/langchain-ai/langchain) — model and tool
  interfaces, agent middleware, and integrations (MIT License).
- [LangGraph](https://github.com/langchain-ai/langgraph) — stateful execution,
  streaming, and checkpointing primitives (MIT License).
- [Open Deep Research](https://github.com/langchain-ai/open_deep_research) — an
  open reference for deep-research workflows and evaluation (MIT License).
