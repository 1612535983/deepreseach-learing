# 网页研究

适用于需要公开网页、近期变化、精确事实或外部出处的研究任务。

## 工作方法

1. 先把问题拆成 2～5 个可验证步骤，明确每一步要回答什么。
2. 搜索词保持简短具体；结果过宽时加入实体名、时间或官方站点限定。
3. 搜索摘要只用于筛选候选来源。关键结论必须读取正文后再使用。
4. 优先选择官方文档、原始公告、论文或数据发布方，再用独立来源交叉确认。
5. 每完成一步就更新计划状态；遇到失败时记录缺口并换查询或来源，不重复无效调用。

## 完成标准

- 关键问题均有正文证据支撑；
- 来源能直接支持对应结论；
- 实时事实注明适用时间；
- 不把未读取的搜索摘要写成确定事实。
