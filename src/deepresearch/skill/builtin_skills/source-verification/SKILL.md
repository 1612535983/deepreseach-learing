# 来源核验

适用于用户要求“核实、验证、有没有依据、给出处”，或结论具有时效性和争议性的任务。

## 核验顺序

1. 把待核验内容拆成独立声明，避免一个引用承担多个不相关结论。
2. 优先读取一手来源：政府或机构原文、官方文档、论文、数据集和当事方公告。
3. 检查发布日期、事件发生日期、适用地区、版本与上下文，避免引用已失效页面。
4. 重要声明尽量寻找第二个独立来源；多个转载同一稿件不算独立交叉验证。
5. 来源冲突时明确列出差异，不用多数票替代证据质量判断。

## 输出纪律

- 只声称正文能够直接支持的内容；
- 区分事实、来源自身观点和研究者推断；
- 无法核验时明确标记“不确定”以及缺少什么证据；
- 引用链接指向实际读取的页面，而不是搜索结果页。
